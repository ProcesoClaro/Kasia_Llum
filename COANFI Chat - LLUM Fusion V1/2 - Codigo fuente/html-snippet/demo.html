Página de prueba

Esta página de ejemplo carga el widget COANFI Chat en la esquina inferior derecha. Ya viene configurado contra los webhooks de producción, por lo que puedes probar una conversación real con KasIA abriendo este archivo en el navegador.

Para instalar el widget en tu web, sólo tienes que copiar el bloque de dos etiquetas <script> que aparece más abajo (o el contenido del archivo snippet.html) y pegarlo justo antes de la etiqueta </body> de tus páginas HTML.
